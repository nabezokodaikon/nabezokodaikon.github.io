ただただシンプルに、
高速に、画像管理

PicSum は直感的に操作でき、高速で動作する画像管理アプリです。
画像管理、画像閲覧のストレスをゼロにします。

Microsoft Store で無料体験

Windows 10/11 対応


特徴

タグ付けによるスマートなファイルの整理

タグによる分類で、整理や検索に役立ちます。

馴染みのある一覧表示

Windowsのような操作で、目的の場所へすばやく移動できます。

高速な読み込み / 高速起動

徹底的にチューニングされており、起動から表示までをスムーズに動作します。

Google Chrome と遜色ないタブ操作

タブ切り替えやウィンドウ分離で、マルチタスクを快適にします。

機能

  • ファイル、フォルダにタグを付けることができます。
  • フォルダ内のどこまで見たかに栞を付けることができます。
  • 高速にサムネイルの一覧を表示します。
  • 画像ファイルを高速に読み込み、描画します。
  • Google Chromeと遜色ないタブ操作ができます。
  • 画像を簡易的に編集できます。
  • 画像形式を変換できます。

対応画像形式

  • Avif AV1 ビデオ拡張機能
  • Gif
  • Heic / Heif HEIF 画像表示オプション
  • Ico
  • Jfif
  • Jpeg
  • Jpg
  • Png
  • Svg
  • Webp WebP 画像表示オプション

マウス操作

  • タブを閉じる。タブ上でミドルクリック
  • タブを切り替える。タブ上でマウスホイール
  • 新しいタブで項目を開く。ファイルリストの項目をミドルクリック
  • 新しいタブでフォルダを開く。アドレスバーの項目をミドルクリック
  • 新しいタブでホームページを開く。ホームボタンをミドルクリック
  • 新しいタブでスターページを開く。スターボタンをミドルクリック
  • 新しいタブでブックマークページを開く。ブックマークボタンをミドルクリック
  • 新しいタブで履歴ページを開く。履歴ボタンをミドルクリック
  • 新しいタブで選択したタグのページを開く。タグ一覧でタグをミドルクリック
  • ページの履歴を戻る / 進む。サイドボタン

キーボード操作

  • タブを閉じる。Control + W
  • 新しいタブを開く。Control + T
  • 新しいウィンドウを開く。Control + N
  • ファイルリストで最下段までスクロールする。Shift + G
  • ファイルリストで最上段までスクロールする。GG
  • ファイルリストで検索する。Control + F
  • 右のタブに切り替える。Control + Tab
  • 左のタブに切り替える。Control + Shift + Tab
  • ページの履歴を戻る。Alt + 左矢印
  • ページの履歴を進む。Alt + 右矢印
  • ページを再読み込み。Control + R / F5
