フォルダごとにどこまで見たかを覚えている「栞機能」で、いつでも続きからスムーズに閲覧を再開できます。

💻 マルチタスク作業

Google Chromeのような直感的なタブ操作やウィンドウの分離機能で、複数のフォルダや画像をスマートに並行表示できます。

開発の動機

画像を見るとき、画像ビューアアプリとエクスプローラーを行ったり来たりするのが不便だと感じていました。
また、複数の画像やエクスプローラーのウィンドウを開いていると、デスクトップが煩雑になってしまいます。
そこで、エクスプローラーのような一覧表示・操作性と、タブ切り替えやウィンドウ分離機能をひとつに統合しました。
PicSumの公開は2024年ですが、その構想は Google Chrome が登場した頃に遡ります。
Google Chrome の素晴らしいタブ操作を画像管理でも実現したいと考え、開発に至りました。

マウス操作

  • タブを閉じる。タブ上でミドルクリック
  • タブを切り替える。タブ上でマウスホイール
  • 新しいタブで項目を開く。ファイルリストの項目をミドルクリック
  • 新しいタブでフォルダを開く。アドレスバーの項目をミドルクリック
  • 新しいタブでホームページを開く。ホームボタンをミドルクリック
  • 新しいタブでスターページを開く。スターボタンをミドルクリック
  • 新しいタブでブックマークページを開く。ブックマークボタンをミドルクリック
  • 新しいタブで履歴ページを開く。履歴ボタンをミドルクリック
  • 新しいタブで選択したタグのページを開く。タグ一覧でタグをミドルクリック
  • ページの履歴を戻る / 進む。サイドボタン

キーボード操作

  • タブを閉じる。Control + W
  • 新しいタブを開く。Control + T
  • 新しいウィンドウを開く。Control + N
  • ファイルリストで最下段までスクロールする。Shift + G
  • ファイルリストで最上段までスクロールする。GG
  • ファイルリストで検索する。Control + F
  • 右のタブに切り替える。Control + Tab
  • 左のタブに切り替える。Control + Shift + Tab
  • ページの履歴を戻る。Alt + 左矢印
  • ページの履歴を進む。Alt + 右矢印
  • ページを再読み込み。Control + R / F5

FAQ

Q. 無料で使うことができますか?

A. 30日間の無料体験期間があり、体験期間終了後は300円で購入いただけます。

Q. ツリービューが無いのはなぜですか？

A. ツリービューは画面幅を圧迫し、水平スクロールが必要になる場合があるため、操作性に難があると考えているからです。代替となるUIを検討中ですので、良いアイデアがございましたらぜひお寄せください。

Q. タグやスターはファイルに書き込まれますか?

A. いいえ。タグやスターはPicSum独自のデータベースで管理しています。ファイルに書き込むことはありません。

Q. ファイルの移動/削除/名前の変更ができません。

A. ファイルの変更は慎重を要する操作です。PicSumは、意図せずファイルが変更される心配をすることなく安心して利用できるよう、閲覧専用の設計になっています。ただし、ファイルの書き出し(コピー)は可能です。
