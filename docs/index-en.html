Motivation for Development

When viewing images, I felt it was inconvenient to constantly switch back and forth between an image viewer app and File Explorer.

Also, displaying multiple images or multiple Explorer windows makes the desktop cluttered.

Therefore, I integrated File Explorer-like list display and operation with tab-switching and window-detaching capabilities.

Although PicSum was released in 2024, its concept dates back to around when Google Chrome first appeared.

I wanted to bring Chrome's fantastic tab operations to image management, which led to this development.

Mouse Operations

  • Close tab: Middle-click on tab
  • Switch tabs: Mouse wheel on tab
  • Open item in new tab: Middle-click on file list item
  • Open folder in new tab: Middle-click on address bar item
  • Open homepage in new tab: Middle-click on home button
  • Open star page in new tab: Middle-click on star button
  • Open bookmarks in new tab: Middle-click on bookmark button
  • Open history in new tab: Middle-click on history button
  • Open tag page in new tab: Middle-click on tag in tag list
  • Back / Forward in history: Side buttons

Keyboard Shortcuts

  • Close tab: Control + W
  • Open new tab: Control + T
  • Open new window: Control + N
  • Scroll to bottom of file list: Shift + G
  • Scroll to top of file list: GG
  • Search in file list: Control + F
  • Switch to right tab: Control + Tab
  • Switch to left tab: Control + Shift + Tab
  • Go back in history: Alt + Left Arrow
  • Go forward in history: Alt + Right Arrow
  • Reload page: Control + R / F5

FAQ

Q. Can I use it for free?

A. There is a 30-day free trial, and after the trial period, it can be purchased for 300 JPY.

Q. Why is there no tree view?

A. A tree view takes up screen width and sometimes requires horizontal scrolling, which we believe reduces usability. We are currently considering alternative UI solutions, so if you have any ideas, please feel free to let us know!

Q. Are tags and stars written directly into files?

A. No. Tags and stars are managed in PicSum's own database. Nothing is written into your files.

Q. I cannot move, delete, or rename files.

A. Modifying files is an operation that requires caution. PicSum is designed to be read-only so you can use it with peace of mind without worrying about unintended file modifications. However, exporting (copying) files is supported.
