image management.

PicSum is an intuitive and fast-performing image management app.
It eliminates the stress of managing and viewing images.

Try for Free on Microsoft Store

Compatible with Windows 10/11


Features

Smart Organization with Tagging

Classifying files with tags helps you organize and search them easily.

Familiar List View

Navigate quickly to your target folders with Windows-like operations.

Fast Loading / Quick Startup

Meticulously tuned to ensure smooth operations from startup to image display.

Chrome-like Tab Operations

Switch tabs or detach windows to make multitasking seamless.

Functions

  • You can tag files and folders.
  • You can bookmark how far you have viewed in a folder.
  • Displays a thumbnail list at high speed.
  • Loads and renders image files at high speed.
  • Tab operations comparable to Google Chrome.
  • Basic image editing.
  • You can convert image formats.

Supported Formats

  • Avif AV1 Video Extension
  • Gif
  • Heic / Heif HEIF Image Extensions
  • Ico
  • Jfif
  • Jpeg
  • Jpg
  • Png
  • Svg
  • Webp WebP Image Extensions

Mouse Operations

  • Close tab: Middle-click on tab
  • Switch tabs: Mouse wheel on tab
  • Open item in new tab: Middle-click on file list item
  • Open folder in new tab: Middle-click on address bar item
  • Open homepage in new tab: Middle-click on home button
  • Open star page in new tab: Middle-click on star button
  • Open bookmarks in new tab: Middle-click on bookmark button
  • Open history in new tab: Middle-click on history button
  • Open tag page in new tab: Middle-click on tag in tag list
  • Back / Forward in history: Side buttons

Keyboard Shortcuts

  • Close tab: Control + W
  • Open new tab: Control + T
  • Open new window: Control + N
  • Scroll to bottom of file list: Shift + G
  • Scroll to top of file list: GG
  • Search in file list: Control + F
  • Switch to right tab: Control + Tab
  • Switch to left tab: Control + Shift + Tab
  • Go back in history: Alt + Left Arrow
  • Go forward in history: Alt + Right Arrow
  • Reload page: Control + R / F5
